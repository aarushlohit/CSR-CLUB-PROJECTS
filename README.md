# 🔥 MACSpoof CLI — MAC Address Spoofer Tool By Aarush Lohit

A lightweight Python-based CLI tool to **view, change, and randomize MAC addresses** on Linux systems for cybersecurity learning and network testing.

---

## 🚀 Features

- 📡 View current MAC address
- 🎲 Generate random MAC address
- ✏️ Set custom MAC address
- ⚡ Simple and clean CLI interface

---

## ⚙️ Requirements

- Linux system
- Python 3.x
- Root privileges (sudo)
